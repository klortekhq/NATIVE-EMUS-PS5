# Sega Model 2

## Status

Research target.

The classic ElSemi Model 2 Emulator is historically important but is not a clean open-source native-port base. MAME contains an open Model 2 implementation and is the safer source-level research path.

Reference:
- https://github.com/mamedev/mame

## Rule

Do not build this target by wrapping the Windows Model 2 Emulator under Wine/Proton.

## Next milestone

Evaluate current MAME Model 2 driver performance/coverage and decide whether a dedicated extraction is technically justified.
