# Arcade hardware family

Arcade is tracked both as a broad MAME target and as first-class board families.

## Explicit board targets

- Neo Geo AES/MVS
- Neo Geo CD
- Capcom CPS-1
- Capcom CPS-2
- Capcom CPS-3
- Sega Naomi
- Sega Atomiswave
- Sega Model 2
- Sega Model 3

## Engine sharing

- FBNeo: Neo Geo + CPS families
- Flycast: Naomi + Atomiswave
- MAME: broad fallback/reference and Model 2 research
- Supermodel: Model 3

The board-specific entries exist so compatibility can be validated independently even when the executable engine is shared.
