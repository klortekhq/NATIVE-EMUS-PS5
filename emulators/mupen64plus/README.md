# Mupen64Plus / Nintendo 64

## Status

Mupen64Plus already has mature dynarec work, and PS5 scene ports exist.

## Goals

- native x86-64 dynarec
- Vulkan-capable renderer path
- shared PS5 JIT/input/audio/filesystem
- standalone execution, even if a RetroArch core is also maintained elsewhere

## Next milestone

Compare the PS5_Mupen64Plus delta with current upstream and identify the minimum standalone host layer.
